JSON Formatter & Validator

Paste JSON to check it, pretty-print it or minify it. It is re-checked as you type, and a syntax error points to its line and column.

→ Open dedicated page

Output


          
How it works
            
Your text goes through the browser's own JSON.parse, which follows the JSON standard (RFC 8259) strictly: no comments, no trailing commas, double-quoted keys only. Formatting is JSON.stringify with the indent you pick.

            
Two things to know. If a key appears twice, the last value wins and the duplicate disappears from the output. And numbers become 64-bit floating point, so integers past 253 (9,007,199,254,740,991), such as some database IDs, can change; the tool warns when that happens.

          

        

      


      
      

        

          
Base64 Encode / Decode

          
Type on either side: text is encoded as UTF-8 and then Base64; Base64 is decoded back to text. Both the standard and the URL-safe alphabet work.

          
→ Open dedicated page

          

            

              
              
            

            

              
              
              

            

          

          
          

            
            
            
            
            
          

          

          
How it works
            
Base64 (RFC 4648) writes every 3 bytes as 4 characters from a 64-letter alphabet, so the output is about a third larger than the input. Text is first turned into bytes with UTF-8, which is why accented letters and emoji round-trip correctly.

            
The URL-safe variant (base64url, RFC 4648 §5) swaps + and / for - and _ and usually drops the = padding; JWTs use it. Decoding accepts either alphabet, ignores spaces and line breaks, and tolerates missing padding. If the bytes aren't valid UTF-8 (an image, say), you get a hex preview instead of garbled text. Base64 is an encoding, not encryption: anyone can decode it.

          

        

      


      
      

        

          
URL Encode / Decode

          
Percent-encode text for a URL, or decode it back. Pick the mode that matches where the text is going.

          
→ Open dedicated page

          

            
            
          

          

            

              
              
              

            

            

              
              
              

            

          

          

            
            
            
            
            
          

          

          
How it works
            
Characters are converted to UTF-8 bytes and each unsafe byte becomes %XX. Component mode is right for one piece of a URL (a query value, a path segment): it encodes everything except letters, digits and - _ . ! ~ * ' ( ). Strict also encodes ! ' ( ) *, leaving only RFC 3986's unreserved set. Form data follows the URL Standard's form encoding, writing spaces as +. Whole URL leaves the URL's structure (: / ? # & =) alone, so don't use it for values that contain those characters.

            
Decoding uses the same mode; in Component mode a + stays a plus sign, while Form mode turns it into a space. A stray % or an escape that isn't valid UTF-8 is pointed out rather than guessed at.

          

        

      


      
      

        

          
Hash Generator

          
MD5, SHA-1, SHA-256, SHA-384 and SHA-512 of text (as UTF-8) or of a file, updated as you type. Files are read in this tab and never uploaded.

          
→ Open dedicated page

          
          
          

            
            
            
            
          

          

          

          
How it works
            
The SHA family is computed by your browser's Web Crypto API (crypto.subtle.digest); MD5 (RFC 1321) is computed by a small script on this page. Text is hashed as its UTF-8 bytes, which matches sha256sum, Python's hashlib and most other tools for the same string. A trailing newline counts, so echo "hi" | sha256sum differs from hashing hi here.

            
MD5 and SHA-1 are broken for security (collisions can be manufactured), so use them only as checksums. None of these is suitable for storing passwords; use bcrypt, scrypt or Argon2 for that.

          

        

      


      
      

        

          
UUID Generator

          
Random version 4 UUIDs, or time-ordered version 7 UUIDs that sort by creation time. Up to 1,000 at once, plus a checker that reads any UUID's version and timestamp.

          
→ Open dedicated page

          

            
            
            
            
          

          

          

            
            
            
          

          

            
            
          

          

          

          

            
            
            

            

          

          
How it works
            
Both versions follow RFC 9562 (which replaced RFC 4122). A v4 UUID is 122 random bits from your browser's cryptographic generator (crypto.randomUUID or crypto.getRandomValues), with the version and variant bits set. Chance of a collision is negligible for any realistic number of IDs.

            
A v7 UUID starts with the current Unix time in milliseconds, so new IDs sort after old ones, which keeps database indexes compact. A batch made in the same millisecond uses a counter so it still sorts in creation order. The trade-off: a v7 UUID reveals when it was created. Nothing here is sent anywhere or stored.

          

        

      


      
      

        

          
JWT Decoder

          
Paste a JSON Web Token to read its header, payload and time claims. Decoding happens in this tab; the signature is shown but not verified.

          
→ Open dedicated page

          
          
          

            
          

          

          

          
How it works
            
A signed JWT (RFC 7519, using JWS from RFC 7515) is three base64url pieces joined by dots: a header, a payload and a signature. This tool decodes the first two and pretty-prints them. exp, nbf and iat are shown as dates and compared with this device's clock.

            
It does not verify the signature. Anyone can write a token whose payload says anything, so never trust a decoded payload until your server has checked the signature with the right key and algorithm. The sample token is the well-known public example from jwt.io. Avoid pasting live production tokens into any website, including this one, even though nothing here leaves your browser.

          

        

      


      
      

        

          
Color Converter

          
Edit any field, or use the picker, and the others follow: HEX, RGB and HSL, with alpha. Includes the WCAG contrast ratio against white and black text.

          
→ Open dedicated page

          

            

            

              
              
            

          

          

            

              
              
              

              
            

            

              
              
              

              
            

            

              
              
              

              
            

          

          

          
How it works
            
HEX and RGB are the same sRGB values written two ways. HSL rearranges them as hue (0–360°), saturation and lightness, using the formulas in CSS Color Module Level 4; HSL is shown to one decimal so converting back lands on the same color. Inputs can be modern or legacy CSS syntax: rgb(0 212 170 / 50%), rgba(0, 212, 170, .5), #0da, #00d4aa80, hsl(168deg 100% 42%).

            
The contrast figure is the WCAG 2.2 ratio between this color and pure white or black. 4.5:1 is the AA minimum for body text and 3:1 for large text. Transparency is ignored in that calculation.

How it works
            
This uses your browser's own RegExp engine, so results match JavaScript exactly; other languages (PCRE, Python, Go) differ in places such as lookbehind support and Unicode classes. Unix Timestamp Converter

          
Convert Unix time (seconds, milliseconds, microseconds or nanoseconds) to dates and back, in UTC or your local time zone.

          
→ Open dedicated page

          
–Unix seconds now · – ms

          

            

              
              
              

              

                
                
              

              

                
                
              

            

            

              
              
              

              

                
                
              

              

                
              

            

          

          

          

          
How it works
            
Unix time counts seconds since 1970-01-01 00:00:00 UTC, ignoring leap seconds. Auto-detect reads the size of the number: under 100 billion is seconds (good until the year 5138), then milliseconds, microseconds and nanoseconds. Pick a unit yourself for millisecond values from before March 1973.

            
Dates are best typed in ISO 8601, like 2026-11-03T14:30:00Z or 2026-11-03 14:30 +05:30. Without an offset, the date is read in the zone chosen above. Other formats are handed to your browser's parser, which varies between browsers. 32-bit systems that store seconds in a signed integer overflow at 2147483647, which is 2038-01-19 03:14:07 UTC.

    CSV ↔ JSON Converter
    
          
    Type on either side to convert. Handles quoted fields with commas, quotes and line breaks inside them, and detects comma, semicolon, tab or pipe delimiters.
    
          
    → Open dedicated page
    
          
    
            
            
            
            
          
    
          
    
            
    
              
              
              
    
            
    
            
    
              
              
              
    
            
    
          
    
          
    
            
            
            
            
            
            
            
          
    
          
    
          
    How it works
            
    CSV is parsed by the rules in RFC 4180: a field wrapped in double quotes may contain the delimiter, line breaks and doubled quotes (""). Blank lines are skipped. With a header row, each line becomes an object; repeated or empty header names get _2 or column_N so nothing is overwritten. Without a header, you get an array of arrays.
    
            
    Values stay text unless you turn on type detection. Even then, numbers with leading zeros (zip codes, IDs like 007) and numbers longer than 15 digits stay text so nothing changes value. Going the other way, nested objects and arrays are written as JSON inside the cell. Spreadsheet apps treat cells starting with =, +, - or @ as formulas, so be careful opening CSV built from untrusted data.

    Character & Word Counter

    → Open dedicated page
    
          
          
          
    
            
          
    
          
    
          
    How it works

      How it works
            
      Each octal digit adds up read (4), write (2) and execute (1) for the owner, the group and everyone else, so 755 is rwx for the owner and r-x for the rest.       CIDR Subnet Calculator (IPv4)
      
          
      Enter an IPv4 address with a prefix (192.168.1.0/24) or a netmask (192.168.1.0 255.255.255.0) to get the network, broadcast, host range and address type.
      
          
      → Open dedicated page
      
          
          
          
      
          
      
            
            
            
            
            
          
      
          
      
          
      
          
      How it works
            
      The prefix length says how many leading bits name the network; the rest number the hosts. A /24 leaves 8 host bits, so 256 addresses, minus the network address (all host bits 0) and the broadcast address (all 1) gives 254 usable hosts. Two exceptions: a /31 has no broadcast and both addresses are usable on point-to-point links (RFC 3021), and a /32 is a single host.
      
            
      The address type comes from IANA's special-purpose registry: private ranges (RFC 1918), carrier-grade NAT (RFC 6598), loopback, link-local, documentation and so on. Leading zeros like 010 are refused because some tools read them as octal. IPv6 isn't supported here.

      Password Generator
      
          
      Random passwords from your browser's cryptographic generator. Generated in this tab, never sent or stored.
      
          
      → Open dedicated page
      
          
      
            
            
            
            
          
      
          
      
          
      
          
      
            
            
            
            
            
            
          
      
          
      
            
            
          
      
          
      
          
        
          
        How it works
            
        Every character is picked with crypto.getRandomValues using rejection sampling, so each allowed character is exactly equally likely (no modulo bias). With “at least one from each set”, whole passwords that miss a set are thrown away and redrawn, which keeps the choice uniform among the passwords that qualify.
        
            
        Entropy is length × log2(pool size), slightly reduced for the each-set rule. The labels are a rough guide: under 40 bits weak, 40–59 fair, 60–79 strong, 80+ very strong. A long passphrase or a password manager's generated password is a fine choice too; what matters most is not reusing passwords.

        How it works
            
        Linear gradients run in the direction of the angle (0deg points up, 90deg right). Radial gradients spread from the center as a circle or an ellipse that fits the box. Conic gradients sweep around the center, starting at the angle; the first color is repeated at the end so the seam is smooth. The first line of the CSS is a plain color fallback for anything that can't draw gradients. All three types work in every current browser.

        Slugs
        
          
        
          
        
            
          
        
          
        How it works
            
        Accents are stripped with Unicode normalization (NFKD), a few letters that don't decompose are spelled out (ß → ss, æ → ae, ø → o, ł → l), apostrophes inside words are dropped, and every other run of punctuation or spaces becomes one separator. With ASCII only off, letters from other scripts are kept, which modern browsers display fine but percent-encode when copied. Max length cuts at a word boundary.

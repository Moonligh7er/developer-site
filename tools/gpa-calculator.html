GPA Calculator

Calculate GPA on the standard 4.0 scale from courses with credit hours and letter grades. Toggle weighted mode for honors/AP courses (+0.5) or AP-only bump. Cumulative mode adds prior GPA + prior credits.

Processing happens entirely in your browser. Nothing is uploaded.

GPA is a credit-weighted average: sum of (grade points × credits) divided by sum of credits. A single-credit course affects your GPA less than a four-credit course with the same grade.

Weighted GPA

Many US high schools bump honors courses by +0.5 and AP/IB courses by +1.0 — so an A in AP Chemistry is worth 5.0 instead of 4.0. This inflates GPAs above 4.0. Colleges usually re-calculate an unweighted GPA from your transcript, so weighted GPA is primarily useful for class rank at high schools that use it.

Cumulative mode

If you enter a prior cumulative GPA and prior credits, the tool combines them with the current semester's courses to give you a new cumulative GPA. Formula: (prior GPA × prior credits + current GPA × current credits) / (prior credits + current credits).

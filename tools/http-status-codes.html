How it works

The list mirrors the IANA HTTP Status Code Registry (last updated 2025-09-15). Most codes are defined in RFC 9110 (HTTP Semantics, 2022), which renamed 413 to “Content Too Large” and 422 to “Unprocessable Content”; the old names still match a search. 418 is listed as reserved: the “I'm a teapot” joke from RFC 2324 is popular, but it was never a real HTTP status.

You will also meet unregistered codes that particular servers invent, such as nginx's 499 (client closed the connection) or Cloudflare's 520–527. They mean something only for that product, so they aren't listed here.

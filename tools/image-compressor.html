How image compression works

JPEG, WebP and AVIF are lossy formats — they get smaller files by discarding detail the eye usually doesn't notice. The quality setting (1–100) controls how much is kept. Near 100 keeps almost everything (big file); around 30 discards a lot (small file, visible blocks and smearing). For most photos 70–85 gives a large saving with a drop that's hard to see. The same number doesn't mean the same thing across formats, so compare the preview, not the number. Switch the preview to “Centre at 100%” to see artifacts the scaled-down view hides.

JPEG vs. WebP vs. AVIF

WebP files are typically 25–35% smaller than JPEG at similar visual quality, and every current browser shows them. AVIF is often smaller still, but fewer browsers can create it, so the option only appears where yours can. Pick JPEG when the file is going somewhere old (some email clients, office software, print shops).

PNG, transparency and animation

PNG is lossless, so it has no quality setting; shrinking a PNG as a PNG needs a colour-reducing quantizer, which browsers don't include. This tool re-encodes PNGs as JPEG, WebP or AVIF instead, which is usually far smaller for photos (screenshots with sharp text can look worse — check the preview). WebP and AVIF keep transparency; for JPEG you pick the fill colour. Animated GIFs and WebPs keep only their first frame. Colour profiles are converted to standard sRGB.

EXIF metadata is stripped

Re-encoding through a canvas drops all EXIF metadata — camera model, GPS coordinates, timestamps. Usually that's what you want before posting a phone photo, but if you need EXIF kept (professional workflows), use a desktop tool instead. The photo's rotation tag is applied first, so pictures stay the right way up. Very large images (tens of megapixels) can take a few seconds; the page stays responsive while the browser encodes.

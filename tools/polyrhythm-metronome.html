What is a polyrhythm?

A polyrhythm is two evenly spaced pulses running in the same span of time, such as three beats against two (3:2, the hemiola). Count the smallest grid both fit into — for 3:2 that’s 6 — and A lands on every 2nd step while B lands on every 3rd. These cross-rhythms run through West African drumming, Afro-Cuban music, Indian Carnatic rhythm, Balkan folk, progressive rock and handpan playing.

Polyrhythm vs. polymeter

Polyrhythm mode fits Layer A’s beats evenly into the time of Layer B’s beats, so both start together every cycle; only the top number of each time signature matters, and the BPM is Layer B’s beat. Polymeter mode plays both layers on the same note grid (the BPM is the quarter note; an x/8 layer pulses twice as fast), so bars of different lengths drift apart and meet again after the number of beats shown above the circle — 7/8 against 4/4 realigns every 8 bars of 7/8.

How to use it

Pick a preset or set each layer’s time signature. Tap the accent circles to cycle strong, weak, ghost and silent beats. The circle shows both layers as rings with a playhead; the grid below lays one cycle out in a line. Tap Tempo (or press T) sets the BPM from your taps; Space starts and stops. Sound starts only when you press Play.

How the timing works

Every click is scheduled on the Web Audio clock about a tenth of a second ahead (a lookahead scheduler), and each note’s time is worked out from its position in the cycle rather than by adding up intervals, so the pulse doesn’t drift and doesn’t depend on the page’s frame rate. A background timer only wakes the scheduler; it never decides when a note sounds.

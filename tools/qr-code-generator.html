Error correction levels

QR codes carry Reed–Solomon error correction at one of four levels. Higher levels spend more of the code on recovery data, so the same content needs a bigger, denser code — but it survives more damage and rougher scans. The percentages are the share of codewords that can be restored.

  • L (Low): ~7%. Clean on-screen codes with lots of content.
  • M (Medium): ~15%. A sensible default.
  • Q (Quartile): ~25%. Printed codes that may get scuffed.
  • H (High): ~30%. Use with a centre logo — the logo hides part of the code and error correction fills it back in.

Quiet zone, contrast and the scan check

Readers find a code by its blank border, so the standard (ISO/IEC 18004) asks for a quiet zone four modules wide; smaller borders often still work on screens but fail in print next to other graphics. Dark modules on a light background scan most reliably; light-on-dark (inverted) codes and low-contrast colour pairs fail on some readers, so the page warns about both. After each change the page tries to read the code back. Where the browser has a built-in QR reader (the BarcodeDetector API, mainly Chrome on Android, macOS and ChromeOS) it decodes the image and compares the text with what you typed. Elsewhere it checks that every module came out the right colour and estimates how much a logo covers. Either way, test with a phone before you print a thousand copies.

Content types and capacity

This tool encodes everything in byte mode as UTF-8, so accents, non-Latin scripts and emoji work with current phone readers. The largest QR code (version 40) holds 2,953 bytes at level L, 2,331 at M, 1,663 at Q and 1,273 at H; non-English characters take 2–4 bytes each. More content means a denser, harder-to-scan code, so keep links short where you can.

Formats

URL: any web link; include https:// so phones open it as a link. Wi-Fi: encoded as WIFI:T:WPA;S:name;P:password;; with special characters escaped; current iPhone and Android camera apps offer to join the network. vCard: a vCard 3.0 contact; scanning opens the phone's add-contact screen. Email: a mailto: link with the subject and body filled in. SVG downloads stay sharp at any print size; PNG downloads are exactly the pixel size shown.

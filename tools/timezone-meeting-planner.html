Why the base date matters

Time zones aren't fixed offsets — most Northern Hemisphere countries shift by 1 hour twice a year for daylight saving time (DST). London is UTC+0 in winter and UTC+1 in summer. Some zones don't observe DST (Arizona, most of Asia). Because DST transition dates differ by country, the difference between two cities can be different in different months.

This tool asks for a meeting date so it can use the correct DST state for each city on that specific day. Uses the browser's Intl.DateTimeFormat API with IANA time zone identifiers — no bundled data files, always current.

Working-hours shading

Hours 9–17 (9am to 5pm) in each city's local time are shaded teal. Look for columns where all cities are shaded — those are the meeting windows that don't inconvenience anyone. If no such column exists (common for very spread-out teams), the least-bad options are usually early-morning or late-evening for one side.

Sharing a time

Click any hour in the grid. The “copy this meeting time” area shows the same moment in all zones as plain text you can paste into a calendar invite or Slack.

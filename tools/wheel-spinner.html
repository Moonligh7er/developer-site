Wheel Spinner / Random Picker

Add entries, spin, get a random pick. Each entry has exactly the same chance, using your browser's cryptographic random number generator, and the wheel always stops on the entry it announces. Remove winners one by one for elimination-style picks, and share a list as a link if you want to.

Processing happens entirely in your browser. Nothing is uploaded or saved.

Picked

One per line. A single line separated by commas also works. Up to 500 entries.

A share link carries your entries after the # in the address. That part isn't sent to the web server, but anyone you give the link to can read the list.

How the pick works

The winner is chosen first, with crypto.getRandomValues(), the browser's cryptographically secure random source. Random numbers that would favour some entries over others (the “modulo bias” you get from squeezing a random number into a smaller range) are thrown away and redrawn, so every entry has exactly a 1-in-N chance. The wheel then spins to a random point inside the winner's slice, never on a border, and the name under the pointer is the name announced.

Shuffle uses the same random source with a Fisher–Yates shuffle. Duplicate entries are allowed; an entry listed twice gets two slices and twice the chance. If your device is set to reduce motion, the wheel turns straight to the result instead of spinning.

Remove-winner mode

After a spin, “Remove Winner” drops that entry from the list, which suits draws, turn orders and elimination games. “Restore Removed” puts every removed entry back.

Sharing via link

“Copy Share Link” copies a link with your entries encoded after the # in the address. Browsers don't send that part to the web server, so the list travels only inside the link itself; anyone who has the link can see it. Opening the link loads the entries. Nothing is added to the address bar unless you open a shared link.
